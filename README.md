# 💬 Gokul's Daily Quote Generator

A clean, minimal quote app built as a personal habit — open it, read something funny or real, and carry it with you through the day.

---

## What it does

- Picks a random **funny** or **slice of life** quote every time you click
- Smooth fade animation between quotes
- Save your favourites within the session
- Copy any quote to clipboard in one click
- Share directly to X (Twitter)
- Fully responsive — works on mobile too

## Run locally

No build step needed. Just clone and open:

```bash
git clone https://github.com/gokulsundarc/Random-Quote-Generator.git
cd Random-Quote-Generator
open index.html
```

Or drag `index.html` into any browser.
